# Numpay Dapp

Numpay is a financial management platform built with React, TypeScript, and Tailwind CSS. This project uses **Bun** as the package manager for fast and efficient dependency management.

## Features

- Modern UI with Tailwind CSS
- Authentication and wallet integration
- Send, request, and manage money
- QR code payments
- Activity and transaction history
- Settings and account management

## Prerequisites

- [Bun](https://bun.sh/) installed (v1.0+)
- Node.js (if required for some tooling)
- Git

## Installation

Clone the repository:

```sh
git clone https://github.com/buildorz/numpay-dapp
cd numpay-dapp
bun install
```
## Environment Setup
Copy the example environment file and update values as needed:

```sh
cp [.env.example](http://_vscodecontentref_/0) .env
```
## Running the project
Start the development server:
```sh
bun run dev
```
The app will be available at http://localhost:5173 (or the port specified in your config).

## Building For Production
```sh
bun run build
```
